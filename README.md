# 🎓 ProjectGuide-AI — Frontend

AI-Powered Academic Project Mentoring & Milestone Tracking Platform for Computer Science & Engineering students and faculty guides.

---

## 📁 Repository Structure

```bash
ProjectGuide-AI/
├── frontend/               # Complete React + Vite SPA
│   ├── src/
│   │   ├── components/     # Navbar.jsx
│   │   ├── pages/          # Auth, Profile, StudentDashboard, FacultyDashboard
│   │   ├── utils/          # Constants, Store, Toast
│   │   ├── index.css       # Unified OLED Dark Design System
│   │   ├── App.jsx         # Routing configuration
│   │   └── main.jsx        # Entry point
│   ├── public/             # Static assets
│   ├── index.html          # HTML shell
│   ├── package.json        # Dependencies & scripts
│   └── README.md           # Detailed frontend documentation
└── README.md
```

---

## 🚀 Quickstart for Frontend

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```

App runs by default at `http://localhost:5173`.
